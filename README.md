# Chemical-X Mart 🛒

An Amazon-style clone project for selling **Powerpuff Girls ingredients** like *Sugar, Spice, and everything nice... plus Chemical X!*  

This project is made with the intent to **learn JavaScript** while building a fun and practical e-commerce style application.  

## Tutorial Reference
This project follows the tutorial by **SuperSimpleDev** on YouTube:  
👉 [Build an Amazon Clone with JavaScript](https://www.youtube.com/watch?v=EerdGm-ehJQ)  

## Tech Stack
- **JavaScript** (Core logic, DOM manipulation)
- **HTML & CSS** (UI & layout)
- *(Optionally extendable with Python for backend or APIs)*

## Features (WIP 🚧)
- Browse Powerpuff ingredient "products"  
- Add to cart  
- View and manage cart items  
- Checkout flow (mock)

💡 *This is a learning project and not intended for production use.*
